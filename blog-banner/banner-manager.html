Kitchen AO Blog Banner 管理

桌面版：文章左右兩旁的直幅 banner（螢幕闊度 1360px 或以上才出現，最闊 300×600）。手機及細螢幕：文章內一個 300×250 banner。每個 banner 可剔選放在哪幾篇文章；多於一個 banner 時會自動輪播。

使用步驟
  1. 修改下面 banner 的文字、圖片網址及連結（右邊即時預覽）。
  2. 在「放在哪篇文章」表格剔選。
  3. 按「產生程式碼」→「複製」。
  4. WordPress 後台 → Code Snippets（WPCode） → 打開「Kitchen AO Blog Banner」snippet（第一次就 Add Snippet → HTML Snippet）→ 全部貼上覆蓋 → Insert Method：Auto Insert，Location：Site Wide Footer → Active → Update。
  5. 日後更新：把 WPCode 內現有程式碼貼到最底「載入舊設定」，改完再產生一次。
